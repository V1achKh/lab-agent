# Замечания преподавателя: за что снижают оценку

Составлено по документу преподавателя «Типичные ошибки студентов, совершаемые при защите Лаб.1
по Электротехнике (каждая ошибка наказывается −1 баллом)» — он лежит рядом,
Типичные_ошибки_Лаб1.pdf. Агент получает пункты этого списка к каждой работе, а готовый отчёт
проверяется по ним (команда review). Каждый пункт — строка, начинающаяся с «- »; можно дописывать свои.

## Оформление

- Имя файла отчёта: «ИУ5-3… Фамилия Лаб.1» (группа, фамилия, номер работы).
- Отчёт выполнен одним шрифтом, формат страницы не меняется на протяжении отчёта (кроме формул и подписей рисунков).
- Отчёт полностью машинописный: формулы — редактором формул (Word, MathType, LaTeX), подписи на рисунках — не от руки.
- Десятичный разделитель — точка или запятая, но один и тот же на протяжении ВСЕГО отчёта.
- В тексте и выкладках у переменных индексы: R₂, а не R2; U_ВХ, а не Uвх.
- В формулах нет символа «*» как знака умножения.
- Нет лишних слов; вместо «подключён параллельно (последовательно) с …» не перечислять все элементы многострочно.

## Схема задания

- Схема нарисована самостоятельно, это не копия картинки задания, элементы не закрашены (окраска задания не повторяется).
- Только российские обозначения элементов.
- Номиналы резисторов по российским правилам: Ом — только число, кОм — буква «к», МОм — «М»; у источников можно В, кВ, А, мА, мкА.

## Описание схемы

- Описание содержит всю информацию, чтобы собрать схему, и не ссылается на рисунок схемы задания.
- В описании только физические элементы: резисторы, провода, точки соединения, клеммы, источники напряжения и тока.
- В описании не упоминаются узлы, «слева», «справа», «верхний», «нижний», номера выводов или клемм («первый», «клемма №»).
- «Параллельно» и «последовательно» — только о виде соединения, а не о расположении на рисунке.
- В начале описания нет полного списка элементов.
- Измерительный прибор не часть схемы; описание заканчивается словами «требуется определить напряжение на …» («ток через …», «разность потенциалов между … и …»).

## Расчёт

- Указан используемый метод вычисления.
- Приведены ВСЕ исходные уравнения: для метода правил (не законов!) Кирхгофа — правило узлов для каждой точки схемы и закон Ома для каждого резистора (токи и потенциалы); для метода узловых потенциалов — уравнения для каждого узла только через потенциалы; для метода контурных токов — рисунок с контурами и уравнения для каждого контура.
- Приведён результат.
- Говорить «правила Кирхгофа», а не «законы Кирхгофа».

## Измерение и погрешность

- Есть описание процедуры измерения: вольтметр (амперметр) постоянного тока подключается параллельно (последовательно) с … (в разрыв провода, соединяющего …), либо «положительная клемма подключается к …, отрицательная — к …».
- Указаны показания прибора; конечные нули в показаниях не отброшены.
- Есть скриншот (рисунок) измерения с результатом.
- Инструментальная погрешность связана с последним разрядом показания, а не с последней цифрой.
- Не используется словосочетание «абсолютная погрешность».
- Необходимость дополнительных измерений обоснована сравнением расхождения теоретического и измеренного значений с теоретически допустимой погрешностью.
- Структура: задание (своя схема) — описание схемы — описание процедуры измерений — измерение с результатом — расхождение теоретических и измеренных значений — (дополнительные измерения) — теоретически допустимая погрешность — сравнение.

## Вывод

- Отчёт заканчивается фразой: «Расхождение теоретических и измеренных значений не превосходит (приблизительно равно) теоретически допустимую(-ой) погрешность(-и)».
