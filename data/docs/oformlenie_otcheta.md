## Основной текст

Шрифт Times New Roman 14 пт, межстрочный интервал одинарный, поля: левое 30 мм (в некоторых отчётах 25 мм), правое 15 мм, верхнее и нижнее 20 мм. Небольшой абзацный отступ. Разделы не нумеруются: каждый начинается с полужирного подзаголовка с двоеточием.

Подзаголовки отчёта по лабораторной работе №1 — в порядке, который рекомендует преподаватель («Типичные ошибки студентов…», п. 12): «Полученное задание:» (самостоятельно нарисованная схема, не копия картинки задания, без заливки элементов), «Описание схемы:» (только физические элементы, клеммы и соединения, без узлов, без «слева/справа/верх/низ», без номеров выводов, без измерительного прибора; заканчивается словами «Требуется определить …»), вычисление (метод и все исходные уравнения: для метода правил Кирхгофа — правило узлов для каждой точки и закон Ома для каждого резистора через токи и потенциалы; результат), «Описание процедуры измерений:» (как подключается вольтметр или амперметр и его показания без отбрасывания конечных нулей), измерение с результатом (рисунок), расхождение теоретического и измеренного значений, при необходимости — обоснованные дополнительные измерения, теоретически допустимая погрешность, сравнение. Отчёт заканчивается фразой «Расхождение теоретических и измеренных значений не превосходит (приблизительно равно) теоретически допустимую(-ой) погрешность(-и)».

Подзаголовки отчёта по лабораторной работе №2: «Полученное задание:» (модель источника, входное напряжение, схема), затем нумерованные шаги: измерение напряжения холостого хода, измерение тока короткого замыкания, таблица нагрузочной характеристики (R, Ом; U, В; I, А), график нагрузочной характеристики, таблицы для определения максимального и минимального выходного сопротивления (Rn, Rn + Δ, Rn − Δ, Un+, Un−, In+, In−, rn), расчёт точки пересечения с ВАХ резистора, экспериментальная проверка, итоговая таблица «Расчёт значений / С помощью программы-симулятора».

Формулы вставляются редактором формул Word (знак умножения «·», не «*»), рисунки — по центру. Имя файла отчёта: «ИУ5-34Б Фамилия Лаб.1». Таблицы — без названий, с единицами измерения в заголовках граф.
