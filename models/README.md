# Сюда кладутся скачанные вручную модели (.gguf)

Каждая модель — в свою папку. Скрипт `scripts/llamacpp.sh` сам найдёт файлы здесь;
если папка пустая — скачает модель с Hugging Face.

```
models/
  gemma12/   gemma-4-12b-it-UD-Q4_K_XL.gguf   ← основной файл
             mmproj-F16.gguf                  ← «зрение» (необязательно, для картинок)
  qwen27/    Qwen3.8-27B-UD-Q3_K_XL.gguf
             mmproj-*.gguf                    ← необязательно
  bge-m3/    bge-m3-q8_0.gguf                 ← эмбеддинги для RAG (ggml-org/bge-m3-Q8_0-GGUF)
```

Имена файлов могут быть любыми — важна только папка. Файл, в имени которого есть `mmproj`,
считается модулем «зрения», остальной `.gguf` — самой моделью. Без mmproj модель не видит
картинки — тогда запускайте команды проекта с `--text-only`.

Большие модели, разбитые на части (`…-00001-of-00002.gguf`), кладите в папку все части —
скрипт возьмёт первую, llama.cpp подхватит остальные сам.
